Flutter + Provider State Management Architecture

Presentation Layer UI Widgets & Screens
  • HomeScreen: Sliver dashboard layout
  • BalanceCard: Displays Income, Expense, Balance
  • ExpensePieChart: FL Chart donut breakdown
  • TransactionCard: Recent entry tile & delete icon
  • AddTransactionScreen: Form & validation
State Management Layer TransactionProvider
  • Extends ChangeNotifier
  • Private state: List<TransactionModel> _transactions
  • Getters: totalIncome, totalExpense, balance
  • Aggregator: expensesByCategory map
  • Mutators: addTransaction(), deleteTransaction()
Reactive Loop Unidirectional Data & Notification Flow
STEP 1 User Interaction
(Add / Delete Entry)
→
STEP 2 context.read()
Dispatches Action
→
STEP 3 State Mutation
Updates List
→
STEP 4 notifyListeners()
Signals Observers
→
STEP 5 Consumer / watch
Rebuilds Active UI
